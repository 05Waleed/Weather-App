# Modern Weather App 🌤️

A **modern, responsive weather application** built with **React**, **Vite**, and **Material UI (MUI)**.  
Search for any city to get the current weather with a sleek UI and smooth animations.

---

## Folder Structure

mini-project-react/

├─ src/
│  ├─ App.jsx
│  ├─ WeatherApp.jsx
│  ├─ InfoBox.jsx
│  ├─ SearchBox.jsx
│  ├─ index.css
│  └─ main.jsx
├─ package.json
├─ vite.config.js
└─ README.md


## Features

- Dynamic gradient backgrounds based on weather conditions
- Real-time weather data via OpenWeatherMap API
- Weather icons and detailed temperature info
- Hover animation and responsive card layout
- Clean, mobile-friendly UI
